# EvoStrategy

Research code and Slurm workflows for evolution-strategy and self-training
experiments with Qwen models.

The current Qwen3 continual-learning and independent-domain experiment suite is
in [`qwen3_continual_baselines/`](qwen3_continual_baselines/).

Model weights, Hugging Face caches, checkpoints, Slurm logs, and generated
result files are intentionally excluded from version control.
